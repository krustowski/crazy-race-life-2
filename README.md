# CrazyRaceLife2 (CRL2)

A GTA SA:MP/open.mp freeroam gamemode scripted in the Pawn lang with SQL (SQLite) connector built-in.

Live servers:

[![](https://widgets.gamemonitoring.net/servers/9019170/560x95.webp)](https://gamemonitoring.net/samp/servers/9019170)

[![](https://widgets.gamemonitoring.net/servers/18949736/560x95.webp)](https://gamemonitoring.net/samp/servers/18949736)


## Features

+ Admin Zone
    + Game editors (property, race and trucking point editting tools)
    + Admin levels 0 to 5 (+ RCON)
    + Granularity for commands
+ ATM for banking services
    + At least one ATM per city/town/village
+ Combat Missions (experimental)
    + Business robbery with numerous NPC shooters
    + Briefcase picking for money exchange ($50k per a Briefcase) at the mission end
+ Deathmatch Minigame
    + Custom arena in the woods
    + "Legal" player killing, no wanted level added per kill
    + 4-minute long matches, 45-second interval before a match for players to join
+ Localization
    + English + Czech + Bosnian (partly, WIP)
+ NPC drivers
	+ 5x Taxi driver per big city + 5x Taxi driver around whole map (20 in total)
	+ 5x Trucking driver
	+ 2x Race driver
+ Personal cellphone
    + Accessed easily via the `KEY_YES` key (Y usually)
    + Send private messages directly to a player
    + Check bank account balance
    + Call a service (car mechanic, pizza delivery, a taxi ride, ...)
+ Prizes
    + Tiki ($10M) and Pumpkin ($1.5M) pickups
    + Hidden on pick up automatically
+ Quests
    + Onboarding and achievement checklist for new players, with cash rewards
    + Defined in the database, progress saved per player
    + Replaced the former tutorial (`/tut` is now an alias for `/quest`)
+ Racing
    + Custom races all across the map
    + Air, ground and naval
    + Stunts
+ Rampage Missions
	+ 5-minute long clashes with NPCs on the street
+ Real Estate
    + Custom spawn point
    + Custom vehicle attached (including the modifitaions)
    + Custom safehouse
    + Up to 7 properties per player
    + Save custom skins (up to 5 per property)
+ Rob Missions
	+ Robberz team: hold LALT/LSHIFT by a commercial property to rob it for up to 20 seconds
	+ Robberies chain into one mission until 5 minutes pass without one
+ Taxi Missions
    + Ad-hoc NPC spawned for a player
    + Randomized customer locations and targets
    + Increased commissions for the taxi rides with done count
    + Areas of operation: LV, SF, LS, or whole map
+ Tow Missions 
    + Car impound service
    + Bonus for a new vehicle model (per mission)
    + Increased commission for the tow mission count and distance from SF Docks
+ Teams
    + Custom salary per team 
    + Special commands available
    + Custom weapons
    + Team chat using the exclamation mark at the beginning of a message (e.g. `!message`)
+ Trucking Missions
    + 15+ trucking points (petrol stations etc)
    + Custom missions
    + Weighted commission/bonus per done mission/delivery

### MapUI (legacy)

MapUI is an util to parse and visualize the database data (coords) on the high-res GTA SA map (source: [reddit](https://www.reddit.com/r/sanandreas/comments/9856u1/high_resolution_map_for_grand_theft_auto_san/)): every place the gamemode puts on the map with its details (race routes and best times, owners, team pay, mission records), map-side stats, and — given the live map — every player and NPC as they move. To run it, go to `utils/mapui` and just run it in console like this:

```shell
cd utils/mapui && go run .
```

The MapUI tool is then available at [http://localhost:8082](http://localhost:8082); see [utils/mapui/README.md](utils/mapui/README.md).

![](.github/img/crl2_mapui_detail.jpg)

*^ Detailed tooltip for a commercial property in the MapUI util (legacy).*

### Web portal

MapUI also runs as part of a web portal, together with a stats dashboard (statsui: leaderboards, live server info, RCON for admins) and these docs, behind a gateway where players sign in with their game account. `make portal` runs it locally at [http://127.0.0.1:8070](http://127.0.0.1:8070); `compose.portal.yml`, a layer on `compose.yml`, runs it in containers, and `make stack-deploy` runs it as a Docker swarm stack. Its sources, these Make targets and that compose file are kept out of the repository for now (the targets in a gitignored `Makefile.local`, which `Makefile` includes when present). See [docs/portal.md](docs/portal.md).


## How to build

Fetch the `sampctl` tool for the `pawn` package management.

```
dnf install sampctl
```

Clone this repo and try to build it using the `build` command:

```
sampctl ensure
sampctl build

# or Simply
make build
```

The compiled `.amx` gamemode file should then pop up in the `gamemodes` directory.

To build with the debug output on, and to run the test suite (on `./omp-server`, against a database built fresh from the migrations):

```
make build DEBUG=1
make tests
```

See [docs/getting-started.md](docs/getting-started.md) for the details, and for the optional airline filterscript (`make airline`).


## How to run

Simply put the compiled `.amx` gamemode file into the `gamemodes` directory of your SAMP server's. Then update the server config file (`config.cfg`, or `config.json`) like this:

```
gamemode crl2
```

```json
[...]
        "main_scripts": [
            "crl2 1"
        ],
[...]
```

The examples above are shown respectively to the config file names mentioned.

### Real Estate

Each property ID has to be unique server-wide. It is recommended to use 5-digit format like `40605`, where:

+ `4` stands for the greater zone ID 
+ `06` stands for a district/block ID (incremented)
+ `05` stands for a property ID within the same district/block

Greater zone IDs:

```
1 - San Fierro
2 - Desert
3 - Las Venturas
4 - Countryside, Farms
5 - Los Santos
```

### Webhook to Telegram

Fetch Go binary from [https://github.com/adnanh/webhook](https://github.com/adnanh/webhook). Then fill Telegram (TG) bot token and chat ID to `configs/webhook.sh` and run it in background using:

```
webhook -hooks configs/webhook.json -verbose &
```
